# Football Dribble

[Play on your phone](https://astjha2012.github.io/football-dribble/)

Published browser build, version 0.5.0. Open in portrait orientation. Tap **Find your flow** for three consecutive encounters. **Runs** also includes one-on-one practice and goal-ending challenges.

- Drag to move; release to stop. Longer drags sprint.
- Pull back to gather and turn. Hold backward near the defender to shield.
- Double tap one side to drop that shoulder, then tap the opposite side and drag to accelerate.
- Keyboard: WASD / arrows, Shift sprint, Q/E feint, C shield.

This is a movement stability update: smoother analog speed, shared footfall/contact timing, and fixes for stop/restart and backward ball control. It remains a prototype using generic character animations; it does not match FIFA animation quality.

Progress and playtest data stay in your browser. The initial load downloads the player models.

This repository contains the production files served by GitHub Pages from the main branch.
The development workspace is maintained separately.
